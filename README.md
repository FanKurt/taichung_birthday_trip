# 台中小壽星生日旅行 App

2026/11/14 (六)–11/16 (一)，2 大 2 小，台中 3 天 2 夜親子生日旅行。

## 開啟方式
- **直接使用**：雙擊 `index.html`，用手機或電腦瀏覽器開啟（不需安裝、不需伺服器）。
- **GitHub Pages**：建立新的 GitHub repository，將本資料夾所有檔案上傳至 repository 根目錄，再到 Settings → Pages，選 Deploy from a branch，Branch 選 `main` 和 `/ (root)`，即會生成分享網址。
- **安裝到手機桌面**：在 GitHub Pages HTTPS 網址使用 Safari「分享 → 加入主畫面」或 Chrome「安裝應用程式」(支援情況依瀏覽器而定)。

## 功能
1. 首頁：生日旅行主題、出發倒數或今天下一站、三日行程入口。
2. 行程：三天時間軸、完成勾選、Google Maps 導航、餐廳撥號、從行程快速記帳。
3. 記帳：預估總額 NT$2,015–4,040（**未包含** 11/14 午餐、住宿、油費與過路費等；樂園門票已購但金額未知）、實際花費、新增／修改／刪除、分類統計。
4. 清單：小朋友用品、大人衣物（含內衣褲與睡衣）、電子票券與個人待辦，完成狀態會儲存。
5. 須知：所有重要地點導航、電話、生日優惠提醒、官網連結與親子設施規則。

所有資料保存在**目前瀏覽器的 localStorage**，不會同步跨手機。記帳頁支援 JSON 匯出／匯入備份。App 內容可離線瀏覽；**地圖導航及開啟外部網站需要連網**。
